Install the extension in about a minute

For Chrome, Edge, Brave and Opera. WatchParty isn't in a browser store, so it installs in Developer mode. You only do this once. Edge calls it "Developer mode" too; in Opera it's at opera://extensions.

  1. Download WatchParty.zip and open it. You'll get a WatchParty folder in Downloads. Leave it there.
  2. Go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose Downloads/WatchParty. Remove any older WatchParty first.
  4. Open a video, click the WatchParty button and start a party. Send the code to your people.
NEWAlready installed? You don't need this page. When an update is ready, the WatchParty button shows this badge. Open it and click Update now.
